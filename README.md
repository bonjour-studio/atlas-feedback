# Atlas · Product website & feedback

The official public website and feedback hub for **Atlas for App Store Connect**, a native developer tool for iPhone and iPad by Bonjour, LLC.

- Website: https://atlas.bonjour.dev/
- Feedback hub: https://atlas.bonjour.dev/feedback/
- Questions and ideas: https://github.com/bonjour-studio/atlas-feedback/discussions
- Bug reports: https://github.com/bonjour-studio/atlas-feedback/issues/new/choose
- Private support: [support@bonjour.dev](mailto:support@bonjour.dev)

Atlas is preparing for its first App Store release. This public repository contains the website and community resources; the app implementation is maintained separately.

## Get help

Use Issues for reproducible product bugs. Include the Atlas version/build, device, iOS or iPadOS version, expected behavior, actual behavior and steps to reproduce. Discussions are for questions, suggestions and workflow sharing. English, Chinese and Japanese are welcome.

Never post App Store Connect private keys (`.p8`), JWTs, API credentials, unredacted customer information or private app data. Billing, privacy and security reports belong in private support. We do not need your private key to investigate feedback.

## Website

The dependency-free static website is published from `main:/docs` using GitHub Pages. It includes English, Simplified Chinese and Japanese product/support pages, feedback channels and the existing published English legal text.

```sh
python3 tools/build_site.py
python3 -m http.server 4173 --bind 127.0.0.1 --directory docs
```

Open http://127.0.0.1:4173/. Page content is generated by `tools/build_site.py`; shared styles are in `docs/assets/site.css`. Core navigation, language switching and FAQ disclosure work without JavaScript. There are no analytics scripts or third-party fonts on this website.

App screenshots use fictional example data and Apple’s official device artwork. See [asset attribution](docs/assets/ATTRIBUTION.md). The existing legal text was mirrored from the public Atlas Notion pages on November 17, 2026; no legal terms were rewritten for this website.

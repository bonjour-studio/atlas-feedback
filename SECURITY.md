# Security policy

Report suspected vulnerabilities privately to [support@bonjour.dev](mailto:support@bonjour.dev?subject=Atlas%20Security).

Include the affected Atlas version/build, device and OS, a description of the issue and reproduction steps using fictional data. Do not post vulnerabilities in public Issues or Discussions, and do not send real App Store Connect keys, JWTs or customer data.

If credentials have already been exposed, revoke or rotate them in App Store Connect before sharing a redacted report.
